# ParcellesRP 1.0.0 - Java 25

Plugin séparé d'EconomyRP.
Il dépend de EconomyRP pour les paiements.

Taille par défaut: 4x4 chunks = 64x64 blocs.

Commandes:
/parcelle info
/parcelle acheter
/parcelle vendre
/parcelle ma
/parcelle inviter <joueur>
/parcelle retirer <joueur>

Compilation:
mvn clean package

JAR:
target/ParcellesRP-1.0.0.jar

Installation:
mettre ParcellesRP-1.0.0.jar dans plugins/ avec EconomyRP.jar.
